# Visitor Counter App

A simple and responsive **Visitor Counter** web application built using **HTML, CSS, and JavaScript**. The application keeps track of the number of visits using the browser's **Local Storage**, ensuring the count persists even after the page is refreshed or the browser is reopened.

## 🚀 Features

- 📊 Displays the current visitor count.
- 💾 Stores the count using Local Storage.
- 🔄 Automatically updates the count on each visit.
- 📱 Responsive and clean user interface.
- ⚡ Lightweight with no external dependencies.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Browser Local Storage API

## ⚙️ How It Works

1. When the page loads, the application checks if a visitor count already exists in the browser's Local Storage.
2. If a count exists, it increments the value by one.
3. If no count exists, it initializes the counter to **1**.
4. The updated count is saved back to Local Storage and displayed on the page.
